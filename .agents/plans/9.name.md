# Add Pokemon Name To Captures

## Summary

Add a `pokemonName: String?` property to `PokemonCardPipelineCapture`, populated from the top-left title area of the selected best-focused card capture. Keep real-time frame detection synchronous by extracting the name only after auto-capture selects a capture.

## Key Changes

- Move the existing card-name extraction pieces from `PokemonFeatures/PokemonOcr` into `PokemonCardTextExtraction` so `PokemonCardPipeline` can reuse them without depending on the feature layer.
- Add `PokemonCardTextExtraction` as a dependency of the `PokemonCardPipeline` target.
- Update `PokemonCardFramePipeline.process(...)` to remain synchronous and continue returning `PokemonCardPipelineFrameResult`.
- Add an async capture finalization path on `PokemonCardFramePipeline`, for example `completeCaptureName(for:) async`, or an internal async step where the camera handles the emitted capture, so OCR runs only for the selected capture.
- Set `PokemonCardPipelineCapture.pokemonName` to the cleaned normalized title from the existing name extractor, preserving useful display text like `Charizard VMAX` while repairing CJK spacing and `ex` suffixes.
- Keep `pokemonName` optional: detection/crop/focus can still succeed when OCR cannot confidently extract a name.

## Tests

- Add pipeline tests proving captures include `pokemonName` when the name extractor returns a title.
- Add a negative-path test proving capture still succeeds with `pokemonName == nil` when OCR returns no usable title or fails.
- Move/adapt existing name extractor, title cropper, normalizer, and candidate selector tests into `PokemonCardTextExtractionTests`.
- Add or adapt sample-based coverage using bundled card samples to assert known names are extracted from top-left title regions.

## Verification

- Iterate with the narrow Swift package tests for:
  - `PokemonCardTextExtractionTests`
  - `PokemonCardPipelineTests`
  - relevant `PokemonOcrTests` that consume captures
- Run `just ready` last because this is a code change.

## Assumptions

- `pokemonName` belongs on `PokemonCardPipelineCapture`, not every live frame result.
- The value should be cleaned display text from the existing title normalization behavior, not raw OCR text.
- OCR should not run on the live video frame queue for every throttled frame.
