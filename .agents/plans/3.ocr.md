# PokemonCardsOcr Binary Interface And OCR Integration Tests

## Summary

Refactor OCR so `PokemonCardsOcr` is the public card-name interface: it accepts encoded image bytes, decodes internally, and returns normalized card information. Keep implementation details private with `__` methods. Add real pytest integration coverage using every tracked sample card, including the currently failing Korean Eevee and Japanese N/Zoroark samples.

## Key Changes

- Add `PokemonCardInformation` return type with:
  - `full_title: str | None`
  - `trainer_name: str | None`
  - `pokemon_name: str | None`
- Add public `PokemonCardsOcr.get_information(image: bytes) -> PokemonCardInformation`.
- Decode bytes with OpenCV internally; raise a clear `ValueError` for invalid or unreadable image bytes.
- Move the remaining name extraction orchestration from `ocr/src/main.py` into `PokemonCardsOcr`; keep `main.py` as a CLI/demo wrapper that reads a sample file and calls `get_information`.
- Rename all helper methods in `PokemonCardsOcr` to double-underscore private methods, including recognizer access, cropping, variants, cleanup, candidate scoring, fallback OCR, and debug-image writing.
- Import `numpy` normally in `pokemon_cards.py`; the staged file currently has a fallback-path `NameError` because `np` is only imported under `TYPE_CHECKING`.

## OCR Behavior

- Preserve current normalization: strip mechanics like `ex`/`V` from returned names and titles.
- Make language handling agnostic to callers by trying the relevant OCR fallback languages internally when the fast recognizer is not confident: Japanese, Korean, and Chinese.
- Improve fallback title extraction so all samples resolve:
  - Use a wider/top-title crop when the existing title crop fails, especially for short trainer prefixes like `N`.
  - Prefer title candidates with supported scripts and known trainer joiners (`の`, `의`, `的`) when splitting trainer and Pokémon names.
  - Keep split-region recognizer results as supporting evidence, but let stronger full-title OCR fill missing trainer/pokemon pieces.
